NudiLens Karnataka Visual Refresh

1. Extract this ZIP.
2. Open the folder in VS Code.
3. Right-click index.html > Open with Live Server.

The interface uses direct Wikimedia Commons thumbnail URLs (rather than Special:FilePath redirect URLs) for the four background photographs. Internet access is required for those photos, Google Fonts, and Tesseract.js. If the browser/network blocks Wikimedia, the dark gradient fallback remains visible.

Image credit and licence links are included at the bottom of index.html. Keep those credits when publishing. The ShareAlike photos require licence compliance; review the source pages before redistribution.
